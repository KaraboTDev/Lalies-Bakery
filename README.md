# Lalies Bakery

A website for Lalies Bakery, based in Thohoyandou, South Africa. Built with plain HTML, CSS and JavaScript — no frameworks, no build step.

## About

Lalies Bakery makes wedding cakes, birthday cakes, scones and biscuits to order. Scones and biscuits are also available in bulk (sold by the litre), which suits church events, school functions and large gatherings. This site shows the menu and pricing and lets customers send an order request.

## Pages

- `index.html` — home page: hero, about, menu & prices, gallery, order form
- `privacy.html` — privacy policy
- `terms.html` — terms & conditions

## Running locally

No build tools needed. Either:

- Open `index.html` directly in your browser, or
- Use the VS Code "Live Server" extension for auto-refresh while editing
